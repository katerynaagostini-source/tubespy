Qu'est-ce qu'une API Key ?
C'est simplement un "mot de passe" que Google vous donne pour que TubeSpy puisse lire les donnees YouTube (stats, videos, niches). Vous ne payez rien et vos donnees restent privees.
1

Verifiez que vous avez un compte Google

Si vous utilisez deja Gmail ou YouTube, vous avez deja un compte Google. Sinon, creez-en un gratuitement :

🌐 Creer un compte Google
accounts.google.com
🔔
Utilisez le meme compte Google que celui de votre chaine YouTube, c'est plus simple.
2

Ouvrez Google Cloud Console

C'est le tableau de bord ou Google gere les "projets" et les cles API. Ne vous inquietez pas du mot "Cloud" — vous n'avez rien a payer.

☁️ Ouvrir Google Cloud Console
console.cloud.google.com
👈 Cliquez ici pour choisir un projet
  • ✓Connectez-vous avec votre compte Google
  • ✓Acceptez les conditions d'utilisation si c'est votre premiere visite
  • ✓Vous arrivez sur le tableau de bord — pas besoin d'entrer une carte bancaire
⚠️
Important : Google peut demander une carte bancaire pour "verifier votre identite". Vous ne serez jamais facture pour l'utilisation gratuite de YouTube Data API (quota de 10 000 unites/jour, largement suffisant pour TubeSpy).
3

Creez un nouveau projet

Un "projet" c'est juste un dossier virtuel pour organiser vos cles. Appelez-le comme vous voulez.

console.cloud.google.com/projectcreate
👈 Tapez "TubeSpy" ici 👈 Puis cliquez CREATE
  • ✓En haut de la page, cliquez sur le selecteur de projet (souvent marque "Select a project" ou le nom d'un projet existant)
  • ✓Cliquez "New Project" (Nouveau Projet)
  • ✓Donnez un nom : par exemple TubeSpy ou YouTube Analytics
  • ✓Laissez "Organization" et "Location" par defaut
  • ✓Cliquez "Create"
Nom suggere TubeSpy
⏱
La creation prend 10-30 secondes. Attendez la notification "Your project is ready".
4

Activez YouTube Data API v3

Maintenant on dit a Google : "je veux utiliser YouTube dans ce projet".

🔗 Lien direct vers YouTube Data API
console.cloud.google.com/apis/library/youtube.googleapis.com
👈 Cliquez ce bouton bleu ENABLE
  • ✓Verifiez que votre nouveau projet est selectionne en haut
  • ✓Vous voyez "YouTube Data API v3" avec le logo YouTube
  • ✓Cliquez le gros bouton bleu "Enable" (Activer)
  • ✓Attendez quelques secondes — vous serez redirige vers le dashboard de l'API
💡
Alternative : Depuis le dashboard, allez dans le menu hamburger ☰ → APIs & Services → Library → cherchez "YouTube Data API v3" → Enable.
5

Generez votre cle API

Derniere etape technique ! On va creer la fameuse cle.

🔑 Page Credentials (Identifiants)
console.cloud.google.com/apis/credentials
👈 Choisissez "API key"
console.cloud.google.com/apis/credentials
👈 Copiez cette cle!
  • ✓Cliquez "+ Create Credentials" en haut
  • ✓Choisissez "API Key" dans le menu deroulant
  • ✓Votre cle apparait dans une popup !
  • ✓Cliquez l'icone copier 📋 pour la copier

🎉 Votre cle ressemble a ceci :

Elle commence toujours par "AIza" suivie de caracteres aleatoires

AIzaSyD-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
🔒
Securite : Ne partagez jamais votre cle publiquement (reseaux sociaux, forums). Elle est liee a votre compte Google. Si elle fuite, allez dans Credentials et supprimez-la, puis creez-en une nouvelle.
6

Collez dans TubeSpy

Retournez dans TubeSpy. C'est la derniere ligne droite !

tubespy.app
👈 Collez + Save!
  • ✓Sur n'importe quelle page de TubeSpy, vous voyez le bandeau "Enter your YouTube API Key"
  • ✓Collez votre cle (Ctrl+V) dans le champ
  • ✓Cliquez "Save Key"
  • ✓Le bouton devient vert : "Saved!"
  • ✓Le bandeau disparait et vous voyez "✔ YouTube API connected"

🎉 C'est termine !

TubeSpy a maintenant acces aux donnees YouTube en temps reel.
Niche Finder, Keywords, Thumbnails, Tracker — tout est actif.

📊

Quotas et Limites (gratuit)

Google vous donne 10 000 unites par jour gratuitement. Voici ce que ca represente :

  • ✓Recherche de niches : ~100 recherches/jour (100 unites chacune)
  • ✓Stats de chaines : ~10 000 requetes/jour (1 unite chacune)
  • ✓Stats de videos : ~10 000 requetes/jour (1 unite chacune)
  • ✓Recherche de mots-cles : ~100/jour (100 unites chacune)
💡
Pour un usage normal de TubeSpy, vous ne depasserez jamais le quota gratuit. Le compteur se remet a zero chaque jour a minuit (heure Pacifique).

❓ Questions Frequentes

Q. Est-ce que c'est vraiment gratuit ?
Oui, a 100%. YouTube Data API v3 offre 10 000 unites/jour sans carte bancaire obligatoire. Google peut la demander pour verification d'identite mais ne facture rien.
Q. Ma cle ne commence pas par "AIza" — est-ce normal ?
Non. Toutes les cles API Google commencent par "AIza". Si votre cle est differente, vous avez peut-etre cree un "OAuth Client ID" au lieu d'une "API Key". Retournez dans Credentials → Create Credentials → API Key.
Q. J'ai une erreur "API not enabled" dans TubeSpy
Vous avez oublie l'etape 4. Retournez dans la Library, verifiez que YouTube Data API v3 est "Enabled" (activee) sur votre projet.
Q. "Quota exceeded" — que faire ?
Vous avez depasse les 10 000 unites pour aujourd'hui. Attendez minuit (heure Pacifique = 9h du matin en France). Ou creez un 2e projet avec une nouvelle cle pour doubler votre quota.
Q. Puis-je utiliser la meme cle sur plusieurs appareils ?
Oui ! La cle n'est pas liee a un appareil. Vous pouvez l'utiliser sur votre PC, telephone, ou meme la partager avec un collaborateur (mais attention au quota partage).
Q. Comment supprimer ma cle si je n'en ai plus besoin ?
Google Cloud Console → APIs & Services → Credentials → cliquez les 3 points a cote de votre cle → Delete.
Q. Google peut-il voir mes recherches TubeSpy ?
Google sait que votre cle fait des requetes YouTube (c'est normal — c'est leur API). Mais TubeSpy tourne 100% dans votre navigateur, rien n'est envoye a un serveur tiers.
